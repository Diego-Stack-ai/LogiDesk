# Dati di collaudo ingestion

I documenti aziendali usati per provare l'importazione devono essere copiati
soltanto nella cartella locale `ingestion-private/`, esclusa da Git.

Struttura prevista:

- `ingestion-private/pdf/`
- `ingestion-private/excel/`
- `ingestion-private/immagini/`
- `ingestion-private/profili/`

Non inserire PDF, Excel, fotografie, DDT o dati personali in altre cartelle del
repository. I test versionati devono contenere esclusivamente strutture o dati
anonimizzati.
